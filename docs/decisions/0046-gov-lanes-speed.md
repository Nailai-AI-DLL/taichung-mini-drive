# 0046 依臺中市道路圖的車道數畫標線、依速限決定其他車輛車速

日期:2026-11-16
狀態：已實作(未 commit)

## 背景
- 臺中市千分之一道路圖(114 年版,data.gov.tw 162899)的道路中心線，每段有左向 / 右向車道數、速限(`docs/research/gov-road-map.md`)。
- Cooper 2026-11-16 選了四個用法中的 1、2:「可以沒問題，就先做 1 與 2」。
  1. 車道數 → 標線(取代依路寬推算)
  2. 速限 → 其他車輛的車速

## 決定
### 資料處理
- `tools/research/gov_road_centerline_csv.py`:R0002 DBF → `data/gov/roads/centerline-114.csv`(沿用 83822 路寬 CSV 的欄位名，加左向 / 右向車道數、單雙向、區分級別)。
- `tools/research/road_lanes_match.py`:沿用 0011 路寬的 R 法配對(空間 + 同名;對不到時只有該名稱的值全部一樣才用名稱)→ `data/gov/roads/lanes-range-a.json`(`byOsmId: {n 每向車道數, spd 速限, via}`)。
  - 每向車道數 = max(左向, 右向)(兩欄幾乎都相同，單行道也填同一個數)。
  - 結果(驗收修正後):範圍 A 可行駛道路 819 km,有車道數 89.5%、有速限 88.9%(以長度計);H 3,931 條、P 187、N 196。
  - 沒有名稱的 way 不配;同名線段只對到不到一半樣本時仍取那些(P)。
- 路寬仍用原本的 83822 資料(不換，避免全區路寬跟著變)。

### 建置(`build.ts` `govLanes`)
- 每條道路寫入 `lanes`、`spd`(world.json `WorldRoad`)。
- 政府路寬被 n 條平行 way 平分時(0011;例：臺灣大道每向又分成快車道、慢車道兩條 way),車道數也平分：整條路共 2 × 每向車道數，分給 n 條(無條件捨去);單行 way 全給行車方向，雙向 way 再除以 2。臺灣大道每向 5 線、分兩條 → 快 2 + 慢 2(公車道沒有單獨畫)。
- 單行道左側緊貼對向時，標線從分界開始排;分界位置記在道路的 `ls`,其他車輛照同一個起點排車道。
- 範圍 A:有車道數的道路長度 731 km、有速限 726 km(總長 817 km)。

### 標線(`tools/map-build/lib/street.ts` `lanePlan`)
- 有車道數時：車道寬 = 可用寬 ÷ 車道數，限制在 `LANE_MIN` 2.8–`LANE_MAX` 3.75 m(推論，台灣車道常見 3–3.75 m);太窄就減少車道數到放得下;太寬時每條 3.75 m、剩下 ≥ 2 m 畫機慢車道實線(沿用 `SLOW_LANE_MIN`)。
- 沒有車道數的路照舊(每 3.3 m 一條)。

### 其他車輛(`src/traffic/traffic.ts`)
- 巡航速度:每台車生成時抽一個係數;路有速限 → 速限 × 0.8–1.0(`TRAFFIC.limitPace`,推論);沒有 → 原本的 30–45 km/h。轉進別條路時用新路的速限重算。
- 車道位置：有車道數時用和標線同一套排法(`laneOf`),車子在車道中心。

## 驗證
- 單元測試 391 項全過(新增：標線依車道數 2 項、車速依速限 1 項、車道中心 1 項)。
- e2e 兩次：高速穿越 > 33 ms 卡頓 0 / 0 幀;路上有其他車輛 30 輛;接送測試一次失敗(既有的偶發問題：接到後 1.5 秒才量不耐煩值，目的地很近時會漲超過門檻，和本次無關)。
- 畫面:`docs/art/lanes-0046/`(臺灣大道平視、俯視，西屯路一段)。

## 驗收(fresh-context 驗收員，唯讀)與修正
- 通過:DBF → CSV 逐筆 130,189 × 19 欄 0 不一致;抽 20 條 way 車道數 / 速限和附近同名政府線段一致;標線與車子車道在非緊貼情況全部一致;換路重算巡航;tsc、vitest。
- 發現並已修正:
  1. 中：單行道緊貼對向時，車子從左緣排車道、標線從分界排，最多偏 6.2 m(273 條受影響)→ 街道生成輸出 `laneStart`,寫進道路 `ls`,`laneOf` 照它排;新增測試(車道中心落在相鄰標線正中間)。
  2. 中低：無名 way 抓到主幹道的值(331 條)→ 無名 way 不配。
  3. 低：平分車道數四捨五入讓總數變多(5 線分兩條 → 3 + 3)→ 改成無條件捨去。
  4. 低：臺灣大道四段 212414972 漏配車道數 → 加 P(部分對到也取)與「H 缺值時用名稱補」。
- 不處理：單行道的政府紀錄左右不等(例：精武路 3 / 1),取較大值;方向判斷資料本身沒有。

## 放棄的方案
- 用新道路圖的路寬取代 83822:會讓全區路寬一起變，不在這次範圍。
- 臺灣大道的公車專用道單獨畫：要先做道路面(分隔島)那一步(研究文件的用法 3)。

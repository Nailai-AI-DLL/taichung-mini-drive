# 0014 小地圖

- 日期:2026-10-31
- 狀態:**已決定**。技術做法自行決定;外觀由 Cooper 2026-10-31 拍板(§3)。
- 範圍:M1 第 9 項，規格見 `production-plan.md` §3.5、`M1-plan.md` 第 9 項與 §5 驗收

## 1. 決定(技術，可逆)

| 項目 | 做法 | 檔案 |
|---|---|---|
| 繪圖 | Canvas 2D,不另開 WebGL。只畫 2D 線條，用不到 3D | `src/ui/minimap.ts` |
| 效能 | 離屏快取(0009 S6,參考 slop-newyork)。道路、綠地、水面先畫進一張涵蓋 ±520 m 的快取;可視圓一超出快取才重畫。每幀只把快取轉個角度貼上，再畫路名、地標、車子 | 同上 |
| 純邏輯分離 | 座標轉換、重畫時機、路名挑選、資料整理放在 `minimap-core.ts`,不碰 DOM,可在 Node 測試 | `src/ui/minimap-core.ts` |
| 資料 | 直接用 world.json 的道路、綠地、水道與地標，不另建資料 | `prepareMapData()` |
| 主要道路 | OSM highway 為 trunk / primary / secondary / tertiary 的道路，畫粗一點、加淡黃色 | `MAJOR_RANK` |
| 路名(仿地圖 App) | 1. 主要道路與一般道路都顯示;主要道路 11 px 粗體深色，一般道路 10 px 灰色;字有淺色描邊，沒有底框。<br>2. 字沿道路方向，轉到 [-90°, 90°),不上下顛倒;直向道路由下往上讀。<br>3. 同一條路上方向差 15° 以內的相鄰路段合成一段直線;直線段至少要有字寬的 0.6 倍長才放字。<br>4. 同名只出一次;主要道路優先，同等級離車子近的優先;最近點放不下就試次近點，最多試 8 個點。<br>5. 不能和其他路名重疊(旋轉矩形，用分離軸定理判斷),不能壓到車子周圍 ±22 px,字框四角都要在圓內。<br>6. 最多 7 個;每 6 幀重挑一次，位置與角度每幀重算。 | `labelCandidates()`、`pickLabels()` |
| 地標圖示 | 圓形，中間一個字：歌、站、驛、府、議 | `LANDMARK_GLYPH` |
| 切換 | M 鍵切換車頭朝上 / 北朝上，畫面中央跳出提示。北方標記「N」沿著外圈轉 | `src/main.ts` |
| DPR | 畫布依 devicePixelRatio 放大，上限 2 | `Minimap.resize()` |

## 2. 驗證

- **單元測試**:`tests/unit/minimap.test.ts`,19 項:
  - 北朝上與車頭朝上的方向(6 個車頭角度);
  - 箭頭角度、北方標記位置;
  - 快取重畫時機;
  - 路名挑選規則：最近點放不下時改用次近點;一般道路排在主要道路之後;路段太短不放;
  - 文字角度與道路平行、不上下顛倒;旋轉矩形重疊判定;短路段合併成直線段;
  - 範圍 A 資料：路名候選點都落在同名道路上(用路名索引反查，誤差 < 1 m)。
- **Chrome e2e**:`tests/e2e/run.mjs`。
  - 可切換模式。
  - **對齊**:兩種模式各做一次。找一個離車子 40–90 m 的道路點 T,它在小地圖上的位置要是道路色;T 對車子的鏡射點(離道路邊緣 > 8 m)要不是道路色。取樣時暫時關掉路名，避免被底框擋住。
    - 突變測試：整張地圖轉 180°、偏移 30 px,兩種模式下都會失敗。
  - 以 72 m/s 高速穿越時，快取重畫最長 1.1–2.0 ms(門檻 8 ms)。
- **驗收後修正**:
  - 路名位置改成每幀從世界座標重算。原本每 6 幀才算一次，轉彎時會和道路錯開。
  - 原本的對齊測試只取樣車頭前方，地圖轉 180° 抓不到，所以改成上面的 T / 鏡射點做法。
  - 道路色容差從 24 改成 8:路名底框 `#F6F4EF` 和白色只差 21,會被誤判成道路。
- e2e 的像素取樣放在效能量測之後。讀回畫布像素(getImageData)會讓瀏覽器卡一幀，實測約 50 ms;這只發生在測試，遊戲本身不會讀像素。

## 3. Cooper 的決定(2026-10-31)

| 項目 | 決定 |
|---|---|
| 預設模式 | 車頭朝上 |
| 大小與範圍 | 維持直徑 200 px、半徑代表 260 m |
| 配色 | 維持：底色米灰 `#ECE8E0`、一般道路白、主要道路淡黃 `#F7E3AE`、車子箭頭用路名牌藍 `#2F6FB5` |
| 路名 | 一般道路的路名也要顯示，「模擬 Google maps 或 Apple maps 的感覺」→ 改成 §1 的路名規則。只參考排版方式，沒有使用他們的資料或圖面 |

## 4. 放棄的方案

| 方案 | 理由 |
|---|---|
| 用第二台 three.js 正交相機從上往下拍 | 要多渲染一次 3D 場景，而且只看得到已載入的格子(半徑 800 m);Canvas 2D 便宜，也能畫還沒載入的區域 |
| 每幀重畫全部道路 | 範圍 A 有 6 千多條道路;快取後每幀只貼一張圖 |
| 預先輸出整張小地圖圖片 | 範圍 A 約 6.6 × 5 km,要清楚就要很大張的圖;用執行時快取，既不用另外建置，也不增加下載量 |
| 字一律水平、加底框(第一版) | Cooper 要地圖 App 的感覺，改成沿道路方向、淺色描邊 |
| 只看單一路段長度決定放不放字 | OSM 把直路切成很多短段，主要道路的長路名幾乎都放不下 |

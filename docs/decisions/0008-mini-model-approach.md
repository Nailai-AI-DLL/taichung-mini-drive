## 1. 參考模型分析

網址:https://sketchfab.com/3d-models/1965-austin-mini-cooper-s-8b063519ced9423db1210bb2423c7d2a(2026-10-12 用內建瀏覽器檢視頁面與 3D 檢視器,未下載)

| 項目 | 內容 |
|---|---|
| 作者 | Ddiaz Design |
| 面數 | 35.8k 三角形、22.6k 頂點 |
| 授權 | CC BY-NC-SA(姓名標示、非商業、相同方式分享) |
| 來源 | 頁面寫明「Based on a Need For Speed Edge/Online 3d model」,也就是從 EA 遊戲取出的模型 |
| 車型 | 1965 年的經典 Mini(三門),和 Cooper 的 F55 五門是完全不同的車 |

**為什麼它看起來對**:這是遊戲公司美術依實車資料手工建模的成品。
- 剪影比例精準:車窗約占車高 40%、柱子細、車頂薄且略為外伸、輪子貼在四個角落、前後懸極短。
- 曲面用手工拓樸控制:轉折處有銳利的摺線,大面才是平滑曲面。
- 零件各自獨立:柱子、窗框、玻璃、鍍鉻條、保險桿、燈具都有真實的形狀與材質。

我的腳本做法是用少數幾個參數化斷面去逼近,形狀的自由度和精準度都差太多。這是方法上限的問題,再調參數很難補上。

**可否直接使用:不建議。**
- 它是從 EA 遊戲取出的模型,上傳者很可能沒有權利用 CC 授權釋出(推論)。
- 車型也不對。

只適合當「什麼叫看起來對」的目視參考。

## 2. 可選路線

| 路線 | 做法 | 優點 | 缺點 / 風險 | 費用 |
|---|---|---|---|---|
| **A. 取得授權清楚的 F55 模型** | 在 Sketchfab、CGTrader、TurboSquid 等平台找**原作者自製**的 F55 五門模型,確認授權後匯入 Blender,換成 Cooper 的配色,減面;可愛化用整體變形處理(輪子放大、車身縮短、車廂加高) | 最接近實車、最快 | 要找到合適的模型,授權需逐一確認;可能要付費;寫實模型和低彩度可愛風格要再調和 | 免費(CC 授權)到約 USD 20–150(not_stated,依實際搜尋結果) |
| **B. 用 Cooper 的實車照片 AI 生成 3D** | 以本 session 可用的 3D 生成工具,從實車照片生成模型,再進 Blender 清理、換色、減面 | 以 Cooper 自己的車為準;授權通常歸使用者(需確認該工具條款) | 生成品質不穩定,常見問題有車輪變形、細節糊、拓樸亂;可能要試好幾次 | 依工具計費(not_stated) |
| **C. 繼續腳本建模,改用尺寸圖描邊** | 用 F55 的公開尺寸(長寬高、軸距、輪距)與正側俯三視圖描出剪影,再細修 | 不依賴外部模型 | 原廠三視圖有著作權;就算比例對了,腳本建模的細節上限仍在;可能還要很多輪 | 0 |
| **D. 委託 3D 美術** | 找人手工建 Q 版 F55 | 品質最高、風格可控 | 時間與費用最高 | not_stated |

## 3. 建議

**先試 A,同時用 B 做一次小實驗比較。**

- A 是業界常見做法(遊戲裡的真實車款通常也是取得模型授權或專門建模),最可能讓 Cooper 一眼認出是他的車。
- B 成本低,可以快速知道 AI 生成在這台車上能做到什麼程度。

不論哪條路線,「Blender 處理 → 匯出 GLB → 遊戲載入」的管線都沿用,已經實作並驗證過。

## 4. 需要 Cooper 決定

1. 走哪條路線(可複選):A / B / C / D
2. 如果走 A,可接受的模型預算上限
3. 如果走 B,是否同意使用本 session 的 3D 生成工具(會消耗該服務的點數)
4. 風格取向:「寫實 F55 + 低彩度配色」,還是「明顯 Q 版變形」?寫實度越高越像實車,Q 版變形越大越可愛但越不像。

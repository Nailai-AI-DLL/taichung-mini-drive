# 0032 專屬造型第一批:三棟百貨

日期:2026-11-14
狀態:已實作,等 Cooper 看過

## 背景
Cooper:「希望每棟都做,可以分階段陸續製作」「然後可以先從百貨公司開始做」。第一批 = 新光三越、大遠百、老虎城(七期三棟百貨)。

## 參考資料
`docs/art/dept-stores-reference.md`:研究員(獨立 agent)查的外觀報告,來源是中英文維基、Wikimedia Commons 照片(約 20 張,附網址與授權)、OSM。**沒有使用任何 Google 產品。** 色碼、比例都是看照片目視估計;查不到的寫 not_stated。
研究過程中更正了一個方位:臺灣大道在兩棟百貨的**東北側**(不是南側),正面朝東北。

## 決定
- 三棟從「一般建築 + 掛名」改成「地標」(`data/landmarks/landmarks.json`),外框照 OSM,模型取代擠出量體;地標的碰撞仍照外框。
- 高度查不到(not_stated),用樓層推估:新光三越、大遠百 14 層 × 5 m = 70 m;老虎城 7 層(上半是影廳)約 38 m。原本 OSM 推估是 44.8 m / 22.4 m。查到實際高度再換。
- 模型(Blender 腳本,`npm run models:landmarks` 一起建;共用工具 `tools/models/landmark_kit.py`):
  | 棟 | 三角形 | 做了的特徵 |
  |---|---|---|
  | 新光三越 `landmark_shin_kong.py` | 972 | 正面銀白大圓筒(每層深色橫線、8 條藍綠直玻璃、最上兩層整圈玻璃)、圓筒頂外挑光環、八角形深色裙樓、紅褐色書擋方柱與背面角塔、紅色簷線繞側牆與背面、背面黃色頂板與玻璃帶 |
  | 大遠百 `landmark_top_city.py` | 404 | 淡薄荷綠水平條紋玻璃正面、頂部內凹露台(4 根白柱,面對正面偏右)、中段凸出玻璃盒、底部金色店面 + 中央玻璃大廳、兩角橘色直條、後棟中灰 + 頂部紫色帶 |
  | 老虎城 `landmark_tiger_city.py` | 316 | L 形兩臂(影城棟較高、西臂 0.85 倍)、淺灰白長條板與水平接縫、底層玻璃店面、影城棟面向廣場的凹口 + 圓柱、轉角兩面藍色招牌色塊、西臂深色外挑屋簷、玻璃樓梯塔 |
- 只有形狀與顏色,不放任何商標、店名字樣或品牌圖案(repo 公開)。店名由遊戲端的文字招牌顯示(樓頂,和第一階段同一套),所以 places.json 改成 `landmark` 但保留招牌。
- 接送點:新光三越、大遠百優先放在臺灣大道(正門那側);原本自動挑的是離形心最近的路(市政北七路 = 後門)。`places.json` 新增 `road` 欄位。
- 地標模型的朝向測試(`tests/unit/landmark-models.test.ts`)加三筆:新光三越光環、大遠百綠色玻璃在東北側,老虎城藍色招牌在東側。

## 沒做 / 已知限制
- 老虎城廣場上的藤蔓圓玻璃筒與下沉廣場:不在 OSM 外框內、位置 not_stated,而且地標碰撞照外框,做了會變成穿得過去的東西。
- 大遠百正面的外傾 / 微弧(角度 not_stated)做成垂直平面。
- 新光三越東南長邊、大遠百後棟背面、老虎城西側與南側背面沒有照片,比照其他面推估。
- 兩棟百貨之間「沒有空橋」只有照片未見,沒有文字來源。

## 踩到的坑
- 新光三越圓筒在遊戲裡是一整片灰、看不到橫線:外框的圓弧是折線,照外框擠出的主體牆比圓筒大,把圓筒整個包住。改成圓筒半徑比擬合圓大 0.4 m、橫線與玻璃再往外 0.2 m。
- 沒有上下蓋的圓柱(色帶)在 `landmark_kit.tube` 裡明確把法向量轉成朝外(遊戲只畫正面)。

## 驗證
- 三棟模型都通過既有的地標模型測試(底面貼齊外框 < 3 m、沒有鏡像、高度正確、不超出外框 > 3 m)與新增的朝向測試。全部 313 項通過。
- 遊戲畫面確認三棟都載入、特徵看得到:`docs/art/places/dept-*.jpg`;Blender 預覽 `docs/art/landmarks/{shin-kong,top-city,tiger-city}-*.png`。
- e2e:第一次失敗(平均 56.8 fps、12 幀超過 34 ms),當時機器負載很高(load average 15.7);重跑兩次都通過(59.5 / 60.4 fps、0 幀超過 34 ms)。其中一次開頭有單獨一幀 66 ms(render),推測是新模型第一次進畫面時編譯材質,待觀察。

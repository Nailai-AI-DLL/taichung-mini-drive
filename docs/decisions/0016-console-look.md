## 1. 現況:為什麼「陽春」(查程式碼,不是猜)

| 面向 | 現況 | 主機遊戲通常有的 |
|---|---|---|
| 光影 | 一盞平行光 + 半球光(`src/render/scene.ts:45–59`),陰影 2048 貼圖;色調映射 Neutral | 環境光遮蔽(SSAO / GTAO)、天空光照、柔和接觸陰影、時段感(午後 / 黃昏) |
| 後製 | **完全沒有**(沒有 EffectComposer) | 調色(LUT)、輕微泛光(bloom)、暗角、反鋸齒(SMAA / TAA)、速度感的動態模糊 |
| 天空 | 漸層色 + 霧(`scene.fog` 260–720 m) | 有雲、太陽光暈、大氣散射的天空;遠景有層次 |
| 材質 | 頂點色純色,建築窗格用著色器畫 | 看方向:寫實系有 PBR 反射;風格化系有精心配色、描邊或手繪感 |
| 主角車 | M0 時 Blender 腳本做的第一版 MINI(`public/models/mini_f55_body.glb`,2026-10-12),Cooper 已退件(0008,落差太大);正式模型排在 M1 倒數第二。載入失敗時才是灰色方塊車。(2026-11-11 更正:初版提案誤寫成「還是灰色方塊車」) | 精緻的主角車是畫面焦點,影響最大 |
| 介面 | 圓形時速表、圓形小地圖、藍色路名牌、文字操作說明(`src/style.css`);沒有標題畫面、暫停選單 | 統一設計語言的 HUD、標題畫面、暫停 / 設定選單、轉場動畫 |
| 鏡頭 | 追車鏡頭 | 速度感(高速時 FOV 拉大、輕微晃動)、拍照模式 |

## 7. 光影與後製樣張(2026-11-11)

**內容**(數值都在 `src/config/look.ts`,都是品味數值)
- 光照:午後斜陽,比原本低、偏暖(`#ffe4c4`、強度 3.1);環境光調低並偏藍,陰影面偏冷、受光面偏暖。
- 天空:頂端藍(`#8fbde6`)漸層到地平線淺色;霧 300–800 m,不超過串流載入半徑,遠處沒載入的地方才不會露出來。
- 雲:60 團低多邊形白雲,高 160–280 m,不受霧影響,一個 draw call(`src/render/clouds.ts`)。
- 後製(`src/render/post.ts`):環境光遮蔽(GTAO,半解析度)→ 輕微泛光 → 色調映射 → 調色(飽和度 ×1.16、S 曲線對比、亮部偏暖暗部偏冷、暗角)→ SMAA 反鋸齒。
- 前後對照:每個效果都可單獨開關。網址 `?fx=off` 是改版前、`?fx=-gtao,-bloom` 是關掉指定效果;`__game.setFx({...})` 也可以。

**技術決定(可逆)**
- 場景只畫一次,畫進帶深度貼圖的 render target(`SceneDepthPass`);GTAO 只用深度重建法向量。
  - 放棄 GTAOPass 預設做法(另畫一次整個場景的法向量):draw call 從約 130 增加到 284,接近 300 的上限;而且每種新材質第一次出現時要編譯法向量著色器,實測卡 100–250 ms。
  - three r186 的 GTAOPass 在建構時傳 depthTexture 會出錯,改成建好後再呼叫 `setGBuffer`。
- 遠處深度精度不夠,重建的法向量有雜訊,霧裡的建築和雲會出現暗點。在 GTAO 著色器插入距離淡出,120–260 m 逐漸取消 AO。若 three 改版、找不到插入點,會直接報錯,不會默默失效。
- 後製時一幀會呼叫多次 `renderer.render`,draw call 改成每幀手動歸零,才是整幀的總數(e2e 的門檻要用)。

**驗證**
- 單元測試 220 項通過(新增 `tests/unit/look.test.ts`:效果開關的網址參數);tsc 通過。
- e2e 14 項通過(這次螢幕 60 Hz):平均 60.6 fps,draw call 最多 155,一般行駛最長單幀 32.4 ms。高速穿越 0 幀超過 33 ms,最長 33.3 ms(在 60 Hz 下等於掉一幀,餘裕很小),單格生成最長 8.5 ms。
- 截圖:改前 `docs/art/look-sample/before/`(`?fx=off`)、改後 `after/`,9 個機位 l01–l09;並排 `compare.jpg`。重拍:`node tools/shots/street-shots.mjs <資料夾> look [fx=off]`。

**已知限制 / 風險**

### 12.1 第一版(2026-11-11)

**做法**:`src/render/mini-car.ts` 的 `createMiniCar`。three r186 內建的 `CarGenerator` 用 WebGPU 節點材質,這個專案是 WebGL,不能直接用,所以自己寫;沿用它「截面放樣」的想法(`LoftGeometry`)。
- **車身**:超橢圓截面(指數 4)沿車長放樣;引擎蓋往前下斜,前後端圓角(車頭比車尾圓)。

- **車頂**:白色,前後圓角,加車頂尾翼。
- **引擎蓋**:黑色雙條紋加兩側細銀線,貼著車身頂面。
- **頭燈**:放大的圓頭燈,有燈筒、鍍鉻框、白色日行燈環、燈心,另有霧燈。

- **車身周邊**:黑色輪拱、側裙、前後下保險桿;五門的車門分割線。
- **車尾**:英國旗尾燈簡化成紅底加淡色十字;單出排氣靠左(推論)。
- **其他**:白色後視鏡,腰線鍍鉻細條。
- **輪子**:深灰輪圈加 5 根淺色輻條。
- **材質**:亮面 `MeshStandardMaterial`,加房間環境貼圖(`RoomEnvironment`)做反射。環境貼圖只給車子用。
- **合併網格**:同材質的零件合併成一個網格,車身約 15 個、每個輪子 4 個。合併前 e2e 的 draw call 是 313,超過 300 的上限。
- **車身尺寸**:長 3.48 m(實車約 4.0 m)、半寬 0.9 m,腰線比原本高;物理碰撞箱不變。
- **對照用**:舊的 GLB 第一版用 `?car=glb` 切回。

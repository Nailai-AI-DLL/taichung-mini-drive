# 0031 知名地點(第一階段:掛名)

日期:2026-11-14
狀態:已實作第一階段;第二階段(每棟專屬造型)待分批

## 背景
Cooper:「知名建築物,大遠百、新光三越、老虎城、麥當勞、蔦屋書店、金錢豹、捷運站 這些七期的著名地點,我想陸續增加上去,作為慈慈的起點與目的地。」
我列了清單(`docs/design/map-expansion-draft.md`),Cooper 2026-11-14 回覆:
- 「17個全做」+ 蔦屋書店(「TSUTAYA BOOKSTORE 台中市政店…市政北二路18之1號2、3樓」)= 18 個。
- 「『先掛名、再挑幾棟做專屬造型』:希望每棟都做,可以分階段陸續製作。」
- 「接送點:混合沒問題」。
- 地圖範圍:「我在思考一下跟你說」(未定)。

## 決定
- 清單與代表色在 `data/landmarks/places.json`(進版控)。位置來源四種:OSM 建築 / 公園 id、既有地標 id、捷運站名、經緯度(開在樓裡的店)。
- 建置(build.ts + `tools/map-build/lib/places.ts`):
  - 每個地點算「接送點」:離地點最近、有名字、寬 ≥ 6 m、非服務道路的車道邊緣外 1 m;不可在任何路面上或建築裡;那一側不行就換對面、再不行換下一條路。捷運站(在分隔島上)一律取馬路對面的外側路邊。
  - 對應的建築標上外牆色(`WorldBuilding.k`)。
  - 知名地點與既有地標的外框往外 30 m 內**不補虛構建築**(第一版被補的高樓包住,從街上看不到)。
  - 寫進 world.json 的 `places`。18 個都找到位置與接送點。
- 遊戲:
  - 外牆:代表色往白色混 55%(整棟塗飽和色太重)。
  - 招牌(`src/render/place-signs.ts`):只有文字,不放商標圖案。有建築的立在樓頂靠接送點那一側;沒有建築的(蔦屋書店、秋紅谷、文心森林公園、3 個捷運站)立在接送點旁的桿子上。已有專屬模型的 3 個地標(歌劇院、市政府、市議會)不立招牌。
  - 小地圖:圓底 + 一個字。
  - 接送點:七成(`PICKUP.placeShare`)從距離範圍內的知名地點挑,其餘或挑不到時用一般路邊;慈慈的台詞帶地點名稱。
- 蔦屋書店:位置用 OSM node 7963491957(brand=TSUTAYA,24.16051, 120.64293),和 Cooper 給的地址吻合。那個點在我們的資料裡沒有對應的建築(OSM 沒畫那棟),先立路邊招牌。Cooper 另外貼了 Google Map 連結,依專案約定(不使用 Google 資料,decisions/0001)沒有開啟。

## 放棄的方案
- 招牌用商標圖案或品牌字體:repo 公開,文字指名風險低、商標圖案風險高。
- 整棟塗代表色:飽和色的 14 層樓太突兀。

## 待辦(第二階段)
- 18 個地點的專屬造型,分批做。第一批(三棟百貨)已做,見 0032。places.json 留了 model 欄位的說明;做好後接到現有的地標模型流程(`npm run models:landmarks`)。優先順序待 Cooper 指定。
- 七期以外的第二批地點(廣三 SOGO、勤美、草悟道、美術館、中友、好市多…)。

## 驗證
- 單元測試 `tests/unit/places.test.ts` 10 項:接送點規則(地點那一側、被佔就換對面、不選服務道路、捷運站取對面、不落在別條路面)、淨空圓內不補建築、只挑範圍內的地點、外牆色與招牌寬度、實際地圖(18 個都在且含 Cooper 點名的 7 類、每個接送點在地圖內 / 不在路面 / 不在建築裡 / 離地點 < 150 m、建築帶外牆色且周圍沒有補的建築)。全部 304 項通過。

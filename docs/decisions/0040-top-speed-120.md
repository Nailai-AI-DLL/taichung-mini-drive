# 0040 極速 60 → 120 km/h

日期:2026-11-16
狀態：已實作

## 背景
Cooper:「車速幫我增加到最快可以到 120,方便我繞整張地圖確認內容。」(0039 建物圖鋪全區後要逐區檢查)

## 決定
- `src/vehicle/params.ts` 的 `maxSpeedKmh` 60 → 120。引擎力、轉向等其他手感參數不動(0017 的轉向收斂在 60 km/h 以上維持 `steerMaxHigh`)。
- HUD 速度條滿格跟著極速(`SPEED_BAR_MAX = maxSpeedKmh`),自動變成 120。
- 測試:`tests/unit/vehicle.test.ts` 極速改成 120 ± 3;0–60 km/h 2–5 秒那項不變(仍通過)。

## 驗證
- 單元測試 370 項全過。
- Claude Code 內建瀏覽器實測：臺灣大道二段往西北的直路，全油門 → 約 6 秒 89 km/h、約 8 秒到 120,之後穩定在 120(最高 120.4)。

## 放棄的方案
- 只做除錯用的加速鍵(不改正式極速):Cooper 要的是極速本身，且 0017 的 60 是當時的品味決定，由 Cooper 改回。

## 待 Cooper
- 繞完地圖後，極速要留在 120 還是改回 60(0017 的市區法規感)。

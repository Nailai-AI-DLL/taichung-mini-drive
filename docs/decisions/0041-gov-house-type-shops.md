# 0041 依建物圖房屋型態決定店面與招牌密度

日期:2026-11-16
狀態：已實作(未 commit)

## 背景
- 0039 已用臺中市建物圖鋪全區;房屋型態(B1B)只用來分透天 / 大樓。
- 我列出建物圖還能用的地方(A 透天街屋排招牌、B 騎樓、C 依結構換外觀、D 獨戶雙併不開店、E 地圖畫建築、F 空地),Cooper 2026-11-16:「先做 A + D」。
- Cooper 先前(0039 背景):「西屯路一段其實都是三到四樓的透天，然後招牌很多。」;更早(0015 §11.11)招牌曾整體減半。

## 決定
- **A 連棟透天(B1B = 3)**:店面判定規則不變(臨路 SHOP_REACH 內、路寬 ≥ SHOP_ROAD_MIN、店面類別),但招牌密度用 0015 減半前的值:每 `SIGN_SPACING_ROW` = 4 m、機率 `SIGN_CHANCE_ROW` = 70%(其他店面仍是每 5 m、45%)。數值是推論，可調(`src/config/furniture.ts`)。
- **D 獨戶、雙併(B1B = 1、2)**:臨路也不開店、不掛招牌。OSM 本身有商店標籤、繼承過來的店面照留。
- 型態只在建置端用(`govType` map),不進 world.json。

## 結果(meta.stats)
- 一樓店面 22,289 → 20,684(獨戶 / 雙併拿掉約 1,600);其中連棟透天店面 16,105。
- 直式招牌 20,132 → 26,922(+34%)。
- world.json 20.73 → 20.85 MB。
- 畫面:`docs/art/gov-0039/compare-signs-xitun.jpg`(上 = 之前，下 = 之後)。

## 測試
- `tests/unit/furniture.test.ts`:同樣 40 段街面，連棟透天店面的招牌數是一般店面的 1.5–2.4 倍(期望約 1.9 倍)。
- `tests/unit/gov-buildings.test.ts`:型態常數(3 = 連棟透天;1、2 不開店;4–6 不受影響)。
- 全部 372 項通過。

## 放棄的方案
- 全部店面都恢復減半前的密度：Cooper 0015 要過減半，只在透天街屋加密比較貼近「西屯路招牌很多」。
- 獨戶 / 雙併改成有院子的獨棟樣式：要新幾何，先不做。

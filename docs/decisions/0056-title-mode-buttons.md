# 0056 開始畫面改成兩顆玩法按鈕(自由探索 / 接送慈慈)

日期:2026-11-21
狀態：已實作

## 背景
- 2026-11-21 審查 H2(`docs/reviews/2026-11-21-project-review.md`):接送途中可用大地圖(0055)快速移動，直接跳到慈慈或目的地，等於作弊。
- Cooper 原話:「修好快速移動和接送的衝突：關於這點，我想把玩法改成選項，進入後原本 按任意鍵開始 改成兩顆按鈕。一顆是 自由探索、另一顆是 接送慈慈 。」

## 決定
- 開始畫面拿掉「按任意鍵開始」,改成兩顆按鈕(`index.html` `.mode-buttons`),也可按鍵盤 1 / 2 選。
  - 自由探索：沒有接送任務;大地圖可點擊快速移動。
  - 接送慈慈：原本的接送玩法;大地圖只能看，不能點擊移動，標題列寫「接送模式不能快速移動」。
- 【推論，待 Cooper 確認】「接送模式不能快速移動」是我對「修好衝突」的解讀;Cooper 只指定了兩顆按鈕。
- 實作:
  - `src/main.ts` `start(mode)`:依玩法呼叫 `bigMap.setTravelEnabled(mode === 'free')`、`pickupSys.start(pos, mode === 'pickup')`。
  - `src/ui/bigmap.ts` `setTravelEnabled`:關閉時不顯示懸停提示、點擊不觸發。
  - `src/game/pickup-session.ts` `start(pos, enabled)`:玩法在開始時才決定，同步接送 HUD 顯示。
- 回到標題(Cooper 2026-11-21:「可以，幫我加上回到標題」):暫停選單新增「回到標題」按鈕(`index.html` `data-action="title"`)。
  - `main.ts` `backToTitle`:取消快速移動、關大地圖、`pickupSys.stop()`(藏慈慈、光柱、目標標記、HUD)、車子回到最近路面並停止，再顯示開始畫面重選玩法。
  - 再選接送會開新的一局(不耐煩歸零);尊敬值照舊保存。
- 腳本相容:`window.__game.start()` 不帶參數時沿用網址 `?mode=free`(否則接送);截圖工具等待的文字從「按任意鍵開始」改成「選擇玩法」,`ui-shots.mjs` 改按 2。

## 放棄的方案
- 接送模式保留快速移動但加懲罰(扣耐心或作廢該局):要另定數值，屬商業 / 手感決策，Cooper 沒選。

## 驗證(2026-11-21,內建瀏覽器實跑)
- 載入完成後狀態為「選擇玩法」,兩顆按鈕可按。
- 按 2:接送 HUD 出現;開大地圖點擊後地圖不關、沒有「讀取中」→ 沒移動。
- 點「自由探索」:沒有接送 HUD;開大地圖點擊後地圖關閉、車子移到福星路。
- 接送 → Esc 暫停 → 點「回到標題」→ 開始畫面出現、接送關閉;再點「自由探索」可快速移動;再回標題按 2,接送重新開局(phase = pickup)。
- `npx vitest run` 538 通過;`npx tsc --noEmit` 通過;瀏覽器 console 無錯誤。

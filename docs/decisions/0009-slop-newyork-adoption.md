## 3. 不採用的部分與理由

- **車子模型**(2026-10-24 修訂):原本判斷「通用轎車,解決不了像不像 MINI」。Cooper 表示可以參考他的做法,所以列為 0008 的路線 E,到 MINI 那一步(M1 最後)再和其他路線一起評估。
- **TSL / WebGPU shader**:我們用 WebGLRenderer,他們的 shader 不能直接搬。換 renderer 是另一個大決策,目前沒有需要。
- **方塊 instancing 建築**:台中的 footprint 不規則,圓角也是我們的可愛化特色。
- **自寫運動學物理**:我們用 Rapier,懸吊和碰撞比較真實,手感已經驗收。
- **NYC Open Data**:台中沒有對應資料。

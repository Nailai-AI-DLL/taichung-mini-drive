## 2. 實測行道樹
- `tools/map-build/gov_trees.py`:KMZ → `data/gov/trees/trees-range-a.json`(e、n、樹種、樹高、地點類別)。
- 建置(`build.ts` `govTrees`)→ `placeFurniture` 的 `govTrees`:
  - 照位置種，但不種在車道上、路口鋪面上(另留 0.5 m)、水面、建築裡(離外框 0.3 m);重複點(< 1 m)去掉。
  - 實測樹 15 m 內(`TREE_GOV_COVER`)不再種規則樹;資料沒涵蓋的路段照舊用規則。
  - 樹種 → 5 種樹形(`tools/map-build/lib/gov-trees.ts` `speciesKind`,推論):椰子類 → 椰子、松柏杉 → 尖塔、小葉欖仁 / 黑板樹 → 層狀、榕 / 茄苳 → 叢生、其他 → 球形。
  - 樹高 → 大小倍率 = 樹高 / 7 m,限制 0.6–1.6(`treeScale`)。存法：樹的第 3 個值 = 樹形 + 10 × round(倍率 × 10)(`encodeTreeKind` / `decodeTreeKind`;舊值 0–4 倍率 1,相容)。Tripo 模型模式(預設)與程式生成模式都套用倍率。
- 結果(驗收修正後的 meta.stats):範圍內實測樹 37,538 → 種下 29,753(其餘落在建築 / 車道 / 鋪面 / 路燈號誌旁);規則樹剩 16,025;總數 18,650 → 45,778。
- 有 869 棵樹種名是亂碼「烏?」(資料本身的編碼問題，推論是烏桕),照「其他 → 球形」處理。

## 4. 夜景第一步
- N 鍵切換(標題畫面與 HUD 按鍵說明加「N 夜景」);網址 `?night=1` 直接開夜景;`__game.setNight(on)` 給測試用。
- 天空、霧、月光、環境光：`LOOK_NIGHT`(`src/config/look.ts`);夜裡關太陽陰影。
- 建築(`building-material.ts`,同一個著色器，加 `uNight`):
  - 每扇窗依既有亂數決定亮不亮，比例依細分類(`NIGHT.lit`:一般 35%、透天 40%、大樓 45%、商辦 60%、學校 20%、公共 35%、廟宇 / 低矮 0)。
  - 窗燈顏色混合：暖黃 `#ffc96b` 60%、冷白 `#e3eeff` 40%(Cooper 選「混合」;比例是推論)。沒亮的窗玻璃變暗。
  - 一樓店面發暖光、招牌板與號誌燈發光：傢俱用新的 `GLOW_CODE`(低矮 + 店面，建築不會出現的組合)標記。
- 泛光夜裡調強(`NIGHT.bloom`),雲的自發光夜裡乘 0.12。
- 第一版店面太亮、過曝 → 店面 0.95 → 0.6、泛光 0.55 → 0.4(門檻 0.55 → 0.6)。
- 不做(第二步):路燈地面光暈、車燈、其他車輛燈;過渡色(Cooper 說先不用)。
- 畫面:`docs/art/night-0042/`(`night-xitun.jpg`、`night-zhongshan.jpg`、`night-qiqi-air.jpg`;`*-v1.jpg` 是調暗店面前)。

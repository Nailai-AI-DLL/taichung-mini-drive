# 0038 地標配色改成照實

日期:2026-11-15
狀態:已實作

## 背景
0037 的配色查核(`docs/art/color-audit.md`)找到 19 項和真實照片不符,主要是玻璃太亮、太淡(M1「方案丙:真實淡雅」刻意調淡)。
Cooper:「配色用完全照實」。

## 決定
- 19 項全部改成查核表 §18 的「建議色碼」(完全照實,不取中間值),9 支腳本:歌劇院(主牆、玻璃、舞台塔)、市政大樓(玻璃、深色方框、內凹面)、議會(玻璃、方洞頂板)、新光三越(面磚、圓筒玻璃、黃板)、舊站(帽頂、雨棚)、林酒店(玻璃)、千禧酒店(方窗、藍玻璃帶、裙樓玻璃)、老虎城(店面玻璃)、秋紅谷(湖水)。
- 只改色碼,不改形狀;重建 GLB 後只有這 9 棟的 GLB 變動(其他 8 棟位元組相同,符合可重現)。其他 8 棟的 Blender 預覽圖重算後只有渲染雜訊,已還原不提交。
- `landmark-models.test.ts` 單側特徵檢查裡用到舊色碼的 5 棟改成新色碼(歌劇院舞台塔、舊站帽頂、市府方框、林酒店玻璃、千禧藍玻璃帶)。
- `docs/art/landmarks-reference.md` 等舊研究報告裡的色碼是當時的紀錄,不回頭改(改 docs 既有檔要建 .bak,而且那是歷史依據);現行色碼以腳本為準,對照表在 color-audit.md §18。

## 已知限制 / 給 Cooper 的提醒
- 查核取的是照片裡的像素(已經含陽光與陰影),遊戲又會再打一次卡通光影,所以背光面會比照片更暗一點。如果覺得太暗,可以只把玻璃類調亮 10–20%。
- 麥當勞、金錢豹、IKEA 沒有可靠白天照片,蔦屋只有黃昏照片、千禧酒店照片是 2013 年 → 這幾棟維持原色或只改有依據的部位。
- 信心「中低 / 低」的 3 項(千禧裙樓玻璃、老虎城店面玻璃、新光圓筒玻璃、新光黃板)也照 Cooper 指示改了。

## 驗證
- 改色以腳本比對查核表的「變數名 + 檔案:行號 + 舊色碼」三者都吻合才替換(19/19 吻合)。
- `npm run models:landmarks` 17 棟全部 MODEL_OK;`npx vitest run` 360 項全過。
- 遊戲畫面:`docs/art/colors/after-{cityhall,opera,council,millennium}.jpg`。

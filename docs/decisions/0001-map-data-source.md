# 0001 地圖資料來源

- 日期:2026-10-12
- 狀態:**已決定**(Cooper 2026-10-12 拍板 Q1 接受、Q13 選 OSM + 政府路寬;見 `production-plan.md` §10)
- 依據:`docs/research/data-licensing.md`、`docs/research/osm-taichung-feasibility.md`

## 背景

需求要求「參考 Google Maps 的資料,路名、主要建築物盡量接近實際」。調查發現:
- Google Maps Platform 開發者條款 §3.2.3 禁止擷取資料((c)(i) 的描繪限制原文只針對 Maps JS API 衛星底圖);一般使用者附加條款 §2.1–2.4 禁止複製、大量下載、建立替代性地圖資料集;Geo Guidelines 禁止從街景影像產生資料。
- Photorealistic 3D Tiles 政策明文禁止抽取或描繪幾何,也禁止離線使用。
- OSM 在範圍 A 的路名覆蓋率(依長度、不含 service 道路)為 97.9%,22 個候選地標都找得到;但建築的實際高度只有 1.3% 有,有車道數的道路約 13%。

## 決定

| 資料 | 來源 |
|---|---|
| 路網、路名、建築輪廓、樓層、水系、公園、鐵道 | OSM(ODbL),一次性下載後離線轉檔 |
| 路寬 | 臺中市政府「道路寬度」開放資料對應到 OSM 道路;對不上的路段用預設寬度表 |
| 地形(M0 確認範圍 A 是否平坦;範圍 B 正式使用) | 臺中市 20m DTM(政府資料開放授權第 1 版) |
| 地標外觀參考 | 自拍照片或開放授權照片 |
| 錯漏修正 | `data/overrides/` 人工覆寫檔 |
| Google 任何產品 | 不進入資料管線 |

## 放棄的方案

| 方案 | 放棄原因 |
|---|---|
| 從 Google Maps 擷取或描繪道路、建築 | 條款明文禁止 |
| Google Photorealistic 3D Tiles 直接當場景 | 條款禁止抽取幾何與離線使用;需綁計費;寫實照片風格和「極簡可愛」衝突 |
| 以 Google 街景作為地標建模參考 | 條款沒有明文處理,屬灰色地帶;改用自有或開放授權照片即可避開(Cooper 已於 Q1 選擇不採用) |
| 國土測繪中心 3D 建物 | 檔案下載已改為收費供應;免費介接服務的授權 not_stated |
| 平臺上的地標 LOD3 模型 | 民間授權,只限在平臺上展示 |
| 手繪/自行設計的虛構台中地圖 | 不符合「接近實際」的需求 |
| 全部改用政府道路資料 | 政府資料有路寬,但 OSM 的路網連通與路名已經夠用,且資料已下載;Cooper 於 Q13 選擇 OSM + 政府路寬 |

## 影響

- 遊戲要顯示「© OpenStreetMap contributors」。
- 使用情境為只在自己電腦玩、最多分享錄影影片(Q4)。影片公開時須附 OSM 與政府資料標示;因 OSM 與政府路寬混用,有人索取時須提供轉換方法(建置腳本 + overrides)。見 `production-plan.md` §9。
- 若日後改為公開散布遊戲,需完成 `docs/research/data-licensing.md` §7.2 的清單。

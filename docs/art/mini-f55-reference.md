## 3. Q 版比例(提案)

以實車約 4.0 m 長、1.73 m 寬、1.43 m 高為基準。比例上的取捨屬品味判斷,初版出來後請 Cooper 看預覽圖確認。

| 項目 | 調整 |
|---|---|
| 車長 | 縮短約 8%(保留四扇門看得出來) |
| 車高 | 車窗帶加高約 10%,整體看起來比較「胖」 |
| 輪子 | 放大約 20%,略往外推 |
| 頭燈 | 放大約 25% |
| 邊角 | 所有邊大倒角,車身側面略為鼓起 |
| 面數 | ≤ 15,000 三角形 |

物理碰撞箱維持 M0 的尺寸(手感已認可),只換外觀。

## 5. Cooper 的實車(2026-10-12 回覆與照片)

Cooper 提供自己車子的兩張照片(`mini60/cooper-own-3q-front.jpg`、`mini60/cooper-own-front.jpg`;含車牌,只留在本機、已 gitignore,車牌不進遊戲),並回覆:

| 項目 | Cooper 回覆 | 照片觀察 | 建模採用 |
|---|---|---|---|

| 車身 / 車頂 | 黑車身、米白車頂 | 黑色車身;車頂米白偏暖 | 車身 `#2A2D33`、車頂 `#E6DFCC` |

# 台中捷運綠線高架車站外觀參考(Q 版低面數建模用)

研究日期:2026-11-14。來源限制:不使用任何 Google 產品。進行中,邊查邊寫。

## 0. 一句話結論(先讀這段)
台中捷運綠線的「車站」在街景上其實是 **三個零件** 組成:
1. **道路中央的月台站體**:坐在高架橋上、比高架橋寬很多的長方盒(約 75–125 m 長、25–32 m 寬,OSM 量測),底部是向內收的淺灰白「船底形裙板」,側面由下而上是「白色水平百葉帶 → 玻璃帷幕帶 → 白色薄平屋頂」,由道路中央分隔島上一排粗圓柱撐起。
2. **路側的「車站連通建築」**(出入口+穿堂,在人行道旁的地塊上,3–4 層方盒),每站立面有自己的**識別色**(南屯=黃、四維國小=橘、水安宮/文心森林公園=綠系、文心崇德=灰棋盤格+銅橘)。
3. **封閉式空橋**:從連通建築約 3 樓高處橫跨車道,接到中央站體(下半實牆、上半一圈帶狀玻璃窗)。
加上兩個綠色小配件:高架軌道外側的「淡綠板+綠框玻璃」防護牆,以及人行道上的「綠色直立站名柱」。

(重要:現在遊戲裡的「一個方塊跨在路上」只對應到零件 1;玩家從地面最常看到的,其實是 1 的底面+3 的空橋+2 的彩色盒子。)

## D. 側面立面(面向道路兩側)
由下往上(中央站體,CJ920 典型,P11/P3):
1. 底部裙板:淺灰白金屬/混凝土包覆,斜面向內收。色 ≈ #DCDDD9(目視估計)。
2. 百葉帶:白色水平鋁百葉/格柵,約 3–4 m 高。色 ≈ #F2F2F0(目視)。
3. 玻璃帷幕帶:透明偏冷灰綠玻璃 + 白色細直框,約 4–5 m 高。玻璃 ≈ #A9C2C6(目視)。
4. 屋簷:白色薄板 ≈ #F5F5F3。
- 底面(從正下方看):沒有包板,灰色鋼梁、電纜架外露 ≈ #8C9196(目視)。
- 柱子:淺灰清水混凝土 ≈ #C8C9C4(目視)。
- 綠色元素位置:
  a. **高架軌道進出站段外側防護牆**:下半淡黃綠實板 ≈ #B9D67E、上半透明玻璃、綠色直框 ≈ #6FAE3C(目視);沿高架一路延伸到站體端牆。(P1、P3、P7、P11、P15)
  b. 豐樂公園站月台側玻璃有白色圓點/葉形的印刷圖案,後方綠色(P13)。
  c. 站名牌、站名柱(見 G)。
  d. 中央站體本身**基本上是白色系,沒有大面積綠色**(信心:中高)。
- 路側連通建築(每站不同,識別色;全部目視估計):
  - 南屯:淺灰直條金屬板 + 黃色波浪色帶 ≈ #F2C81E;下部深灰石材 ≈ #4E5054。(P5、P8)
  - 四維國小:淺灰金屬板 ≈ #C9C7C2 + 橘黃細線條 ≈ #F0A11E。(P9)
  - 水安宮:綠色系曲線色帶(淺綠 ≈ #A8D46F、黃綠 ≈ #C7D84A、深綠 ≈ #5FA83A)+ 一條植生牆。(P7)
  - 文心森林公園:綠底 ≈ #7DC243 + 大圓形圖案(含植栽圓、藍綠圓)。(P12)
  - 文心崇德:深淺灰棋盤格大方塊(≈ #8E9296 / #D3D4D2);入口量體為銅橘色斜板 ≈ #C8653A。(P10)
  - 市政府:灰褐色直條格柵 + 轉角整片綠色調玻璃帷幕。(P16)
  - 文心中清:銀灰金屬板。(P0)
  - 文華高中、文心櫻花、豐樂公園:not_stated(本輪沒看到清楚的路側照片)。

## F. 最有辨識度的特徵(建議造型優先順序)
1. **白色長盒站體 + 船底形裙板**:在高架橋上方,寬度約為高架橋的 3 倍(28 m vs 9 m),裙板底比軌道梁底略低或齊平,斷面倒梯形(上寬 28、下寬約 14–18,高 3–4 m,比例為目測)。
2. **三段式水平條紋側立面**:白百葉帶(約 1/3)+ 玻璃帶(約 1/2)+ 白薄屋簷(約 1/6);CJ930 站換成弧形屋簷。
3. **封閉空橋 + 彩色路側方盒**:空橋長 ≈ 道路半寬 + 人行道(約 15–30 m),連到一棟 3–4 層、帶識別色色帶的方盒。
4. **綠框玻璃防護牆**沿高架接入站體兩端(淡黃綠下半板 + 綠框)。
5. **中央一排粗圓柱**(單排、位於分隔島),站體段密集。
(1–3 為最關鍵三項。)

## G. 站名標示
- **人行道綠色站名柱**:立在出入口前人行道上;頂部白底方框放中捷 logo,柱身綠色,直排白字中文站名 + 英文站名;目測高約 2.5–3 m、寬約 0.5 m。(P1、P6、P8)信心:高
- **出入口門楣**:綠色橫長站名牌,寬約 3–4 m、高約 0.6 m(目視)。(P8)信心:中
- **中央站體外牆上的大型站名字**:not_stated(本輪照片中沒有看到)。

- 日期:2026-10-24(調查);2026-10-31 落檔
- 用途:給 Blender Python 腳本建模用。建模的人看不到實景,本文件只講**剪影、比例、主要特徵、顏色**,不講細節。

## 0. 方法、資料來源與標示規則

### 0.1 限制(已拍板,不可違反)

- **不使用任何 Google 產品**(Maps、街景、Earth、Google 圖片搜尋結果)當參考(`docs/production-plan.md` §4.2)。
- 外觀參考只用開放授權照片(維基共享資源 Wikimedia Commons)。照片**只看、不下載、不放進遊戲**;本文件只記網址與授權。
- 建築外觀依著作權法第 58 條可以利用,但依第 64 條要**明示出處**(`docs/research/data-licensing.md` §5.b)。所以每棟都記錄建築師;查不到的寫 not_stated。

### 0.2 標示規則

- **【事實】**:有出處(OSM、維基百科、官方網站、新聞)。
- **【計算】**:由 OSM 座標算出,算法見 0.4。
- **【目視】**:我在 Commons 網頁上看照片後的描述。這是觀察,不是文字出處;比例數字屬於估計。
- **【推論】**:建議或推估,沒有直接出處。所有色碼都是推論。
- **not_stated**:查過但查不到。

### 0.4 外框計算方法(【計算】的來源)

1. 從 `range-a_area.json` 取出 way 的 `geometry`(經緯度節點)。
2. 投影:以多邊形平均緯度 φ0 做等距圓柱投影,x = R·cosφ0·Δλ、y = R·Δφ,R = 6,371,008.8 m(與 `tools/research/osm_landmarks.py` 相同)。
3. 面積:鞋帶公式。
4. 外框長寬:對凸包逐邊旋轉,取面積最小的外接矩形;長邊 = 長、短邊 = 寬。
5. 主軸方位角:最小外接矩形長邊方向,從正北順時針量,取 0–180°。
6. 交叉檢查:另用 TWD97 TM2(EPSG:3826)正算公式投影,並用 `tools/research/twd97_to_wgs84.py` 的 `tm_inverse` 反算回經緯度,往返誤差 < 1e-9 度。兩種投影的長寬差 ≤ 0.4 m、面積差 ≤ 0.3%、方位差 ≤ 0.3°(TM2 方位是方格北,與真北差約 0.15°)。
7. 照片角度:相機座標取自 Commons 的 camera coordinates。算「相機 → 地標形心」的方位與距離。這假設相機對著建築拍,屬【推論】;有標【目視】的照片才實際看過畫面。

> 重現:上述步驟可用約 80 行 Python 完成(只用標準函式庫 + 專案的 `twd97_to_wgs84.py`)。本次的腳本放在 session 暫存區,沒有放進專案(本任務限定只新增本檔)。

### 1.2 量體構成

- 【目視】整體是一個**平頂的大方盒**。四面牆是淺灰白色,牆上散布小圓點(呼吸孔)。
- 【目視】牆面被挖出幾個**上下寬、中間收腰的瓶狀 / 葫蘆狀開口**,開口邊緣有一圈白色細框:
  - 有的開口填滿深色反光的玻璃帷幕;
  - 有的是往內凹的「洞窟」,可以看到裡面白色的管狀曲面。
- 【目視】開口的上緣會翻出牆頂,讓牆頂輪廓出現波浪狀缺口。長邊立面約有 3–5 個大開口(包括轉角包覆的)。
- 【目視】屋頂是空中花園:有白色有機曲面的小突起,加上綠地;屋頂中後段有一個**深灰色長方盒**(推論是舞台塔)。
- 【事實】6 樓空中花園(中文維基)。

### 1.3 最有辨識度的方向

- 【計算+目視】長邊立面朝東南(法線約 122°),面對惠來路二段(OSM 道路距形心約 111 m),前面是大廣場和圓形水景。從東南方看,能同時看到最多瓶狀開口。
- 【推論】遊戲中從惠來路 / 市政北路一帶往西北看最好認。

### 1.6 Q 版建模建議

用 7 個基本形體:

1. **主盒**:圓角方盒 121.8 × 71.7 m,高約 32 m(主牆高 not_stated;【推論】取總高約 85%),Q 版可以把高度放大到 1.1–1.2 倍。
2. **瓶狀開口 × 4(一定要有)**:長邊各 2 個,短邊可省略。用「兩個圓柱 + 中間細頸」的葫蘆形布林減去主盒,上緣穿出牆頂。
3. **開口白框**:每個開口沿邊做一圈 0.6–1 m 的白色細邊(用 inset / solidify)。這是遠看最容易認出的特徵。
4. **玻璃填面**:2 個開口填深藍綠玻璃色;另 2 個做成內凹洞窟(內部白色)。
5. **屋頂舞台塔**:深灰方盒,約主盒長度 1/4,高出屋頂約 6 m(【推論】讓總高 ≈ 37.7 m)。
6. **屋頂綠地**:薄平板,加 2–3 個白色小圓丘。
7. **前廣場圓形水景**(選配):扁圓柱,淡灰藍。

- 一定要有:方盒剪影、葫蘆形開口、白框。
- 可以省略:呼吸孔小圓點(改用貼圖點或直接不做)、內部曲牆、屋頂細節、玻璃分格。

### 2.6 Q 版建模建議

用 8 個基本形體:

1. **高架橋基座**:長方塊,沿 65.8° 方向,長約 320 m、高約 12 m(【推論】,含 1–2 樓)。
2. **大殼屋頂 A(一定要有)**:半圓柱殼(壓扁的拱),長約 130 m,兩端微微上翹。
3. **長殼屋頂 B(一定要有)**:同上,長約 180 m,比 A 稍低,和 A 前後錯開接續。
4. **屋頂肋條**:沿殼方向做 6–10 條淺凸肋(或用法線貼圖),做出「蝴蝶翅脈」感。
5. **樹枝狀柱 × 4–6(一定要有)**:西側懸挑邊,一根圓柱往上分成 3 叉,白色。
6. **玻璃立面**:殼下的半透明平板。
7. **前階梯**:寬階梯塊,從地面上到 2 樓。
8. **月臺雨棚**(選配):殼內的薄板,不做也看不出來。

- 一定要有:兩片銀灰弧殼的剪影、白色樹枝柱。
- 可以省略:太陽能板分格、月臺、公共藝術、內部大廳。
- 頂點總高控制在 37 m(【事實】)。Q 版可以讓殼更圓、更鼓。

## 9. 方法決策與放棄的方案

- **照片角度用 Commons 相機座標推算**,不靠人工描述。理由:可重現、有數字。限制:相機座標不一定準,也不保證鏡頭朝向建築,所以標成【推論】;有實際看過的照片另標【目視】。
- **用瀏覽器檢視 Commons 縮圖做目視描述**。理由:任務說明「建模的人看不到實景」,只有文字描述不夠。照片沒有下載或存檔。
- **放棄**:讀取文化部〈國定古蹟臺中火車站保存計畫報告書〉PDF(超過 10 MB,WebFetch 無法讀取;另外下載檔案需要另外取得同意)。這是舊站尺寸最可能的權威來源,建議之後由 Cooper 決定要不要下載查閱。
- **放棄**:國家文化資產網(nchdb.boch.gov.tw)。網頁要用 JS 動態載入,抓不到內文。
- **放棄**:透過 web.archive.org 查證聯合報〈建築師張樞〉報導內文(工具無法存取 / 這次操作被中止)。
- **不使用 Google 任何產品**:全程只用 OSM、維基百科、Wikidata、Commons、官方網站和新聞頁。
- 依任務限制,本次只新增本檔。決策紀錄沒有另外寫進 `docs/decisions/`;如果需要,請 Cooper 指示。

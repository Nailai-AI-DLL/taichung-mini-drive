## 優點

### 1. 城市真實度是最大強項(事實)
- 道路：路寬(市府 83822)、每向車道數與速限(市府道路圖，覆蓋 89%)、號誌依 OSM(沒對到的路口 501 → 4)。
- 建築：市府建物圖 12 萬棟、實際樓層數;透天街屋有店面與密集招牌。
- 地標 48 個、知名地點 62 個(31 個自製 GLB);捷運高架、74 快速道路高架、DTM 地形。
- 每個數字都有來源與決策文件可追(0011、0039、0046、0047)。

### 2. 工程底子扎實(事實)
- TypeScript `strict`、src 沒有 `any`、`tsc` 0 錯誤;單元測試 36 檔 536 項全過(28–34 秒)。
- 測試直接驗證建置產物：所有分區檔套用後和 world.json 逐格 100% 一致。
- main.ts 593 → 442 行，拆出 WorldChunkManager、TrafficSystem、PickupSession、PerfTracker,部分可在 Node 測。
- 分區串流(1 km 資料區塊 + 250 m 網格)有遲滯、每幀預算、骨架保底;最密一格生成 8.4 ms。
- 渲染批次化：每格一個 mesh、樹 / 車 / 機車用 InstancedMesh、窗格用 shader 生成，不用貼圖。
- CI 先跑測試才部署。

### 3. 畫面風格一致(事實 / 品味項)
- 圓角卡通建築、低多邊形樹、Q 版 MINI;HUD 有路名牌、不耐煩條、方向箭頭、小地圖。
- 夜景(窗燈、招牌、車燈、大燈)有氣氛。

### 4. 合規意識好(事實)
- 不用 Google 資料;金鑰、參考照都在版控外(git grep 沒掃到金鑰)。
- 招牌只放文字、不放商標;授權研究 353 行、條款逐條引用。
